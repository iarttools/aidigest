# aidigest launch kit

Este documento contiene mensajes listos para presentar aidigest sin exagerar sus resultados. La promesa que sí podemos demostrar es concreta: menos contexto innecesario, una medida antes/después y una herramienta gratuita que se puede probar en segundos.

## Descripción corta para GitHub

> Free, local-first context filter for AI agents. Clean web pages, remove noise, flag prompt injection patterns, and measure real token savings before content reaches your model.

## Frase principal

> Tu IA no necesita leerlo todo.

## Mensaje corto en español

Internet está lleno de información útil y de mucho ruido. aidigest limpia las páginas antes de que lleguen a tu IA, elimina contenido repetido, detecta señales de prompt injection y muestra cuántos tokens has ahorrado.

Es gratis, open source, local por defecto y se puede probar con un solo `.exe`.

En la demo incluida: **259 → 126 tokens**, un **51 % menos**.

## Qué no debemos prometer

- No decir que ahorra un porcentaje fijo en todas las páginas.
- No presentar la gráfica de modelos como una tarifa actual de proveedores.
- No decir que detecta todas las inyecciones o que sustituye la revisión humana.
- No ocultar que algunos clientes ignoran proxies y necesitan configuración MCP explícita.
